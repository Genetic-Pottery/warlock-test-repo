## Structure

- Duplicated CouponApplyGateway/ResolveGateway/CompactGateway/ValidateGateway/ProjectGateway/ReconcileGateway/EmitGateway/SettleGateway classes, each running attempts-window probes on a CouponId.
- Defines Couponstore Applyer/Resolveer/Compacter/Validateer/Projecter/Reconcileer/Emiter/Settleer, each loading via CouponstoreStore.Load, stamping, retrying Save, and returning ErrCouponstoreMissing.
- Repeated Dispute*Gateway classes (Apply/Resolve/Compact/Validate/Project/Reconcile/Emit/Settle) probing DisputeId via clock-based options.
- dispute_repo.py: disputerepo projections (DisputerepoApply, Resolve, Compact, Validate, Project, Reconcile, Emit dataclasses), folding matching events into a windowed row buffer via apply/resolve/etc and drain().

- schema.sql: 30 identical tenant-scoped tables (ledger, invoice, quota, webhook, session, audit, ...): id, tenant, amount, stamp, plus a tenant/stamp index each, underlying all Go store and Python repo files.
