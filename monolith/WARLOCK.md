## Structure

- Defines the Clock interface (now(): Date) and systemClock, a Clock implementation backed by the real Date.
- Duplicated Apply/Resolve/Compact/Validate/Project/Reconcile/Emit/Settle gateway classes, each retrying an async probe(id, round) over opts.attempts using RollupId and a Clock.
- Repeats a ShardXGateway class (apply/resolve/compact/validate/project/reconcile/emit/settle) with its own Options interface, each running attempts probes summing id.length+round+window.
- Defines repeated Entitlement*Gateway classes with matching Options interfaces; each wraps a Clock to probe an EntitlementId and sum lengths, duplicated identically across the file.
- Defines 28 near-identical tables (ledger, invoice, tenant, quota, ... shard), each with id, tenant, amount, stamp and a tenant/stamp index.
- Defines nine near-identical Load/mutate-Stamp/Save(retries N) worker types over *LedgerstoreStore, all returning ErrLedgerstoreMissing on failure.
- Duplicated Ledger*er structs, each load/stamp/save-retry against LedgerStore; repeats with incrementing retries values, duplicate type declarations of the same names.
- Repeated (duplicate, non-compiling) Export*er struct/New/method groups load/stamp/save an Export via ExportStore, retrying on ErrExportMissing.
- Repeats duplicate Applyer/Resolveer/Compacter/Validateer/Projecter/Reconcileer/Emiter/Settleer types redefining ReconcileApplyer etc.; non-compiling due to repeated declarations.
- Defines Retry*er types each wrapping RetryStore with a clock and increasing retry counts, retrying Load/Save until success or returning ErrRetryMissing.
