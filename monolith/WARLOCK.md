## Structure

- Each Go *.go entity file (audit.go, ledger.go, refund.go, shipment.go, etc.) pairs with a matching *_store.go that supplies its Load/Save-backed Store type.
- Every *Gateway.ts file imports Clock from clock.ts and uses systemClock as its time source for probe-based apply/resolve/compact/validate/project/reconcile/emit/settle methods.
- Python *_projection.py and *_repo.py files fold events matching their own "kind" string into windowed rows, then drain() flushes them for downstream consumption.
- schema.sql defines one table per domain entity (ledger, invoice, quota, webhook, shipment, etc.), each of which has a corresponding Go *.go or *_store.go and/or Python projection/repo file.

## Rules

- Every Store-backed entity's Load returning nil yields its ErrXMissing sentinel rather than a zero value.
- Save is retried up to a fixed per-operation retries count (2 for Apply up through higher counts for later variants) before giving up with the Missing error.
- Each schema.sql table's tenant_stamp index orders by stamp DESC to support recent-first tenant queries.
- Projection dataclasses ignore any event whose "kind" does not match their own domain string, returning None.
