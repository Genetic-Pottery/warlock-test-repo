# monolith

Flat collection of Go, Python, and TypeScript modules modeling multi-tenant billing/ops entities (ledger, invoice, quota, payout, refund, shipment, tax, usage, session, etc.) via near-duplicated store, repo, projection, and gateway patterns, plus a shared SQL schema.
