# src

Holds root-level source utilities: an API stub for fetching a cart by id, and a legacy retry helper for calling a function a fixed number of times.

- `api.ts` (130 B) — Defines BASE_URL constant and async fetchCart(id) stub returning the given id as a string. · declares `BASE_URL`, `fetchCart`
- `legacy.js` (145 B) — Defines RETRY_LIMIT (3) and retry(fn), which calls fn() that many times in a loop; exported via module.exports. · declares `RETRY_LIMIT`, `retry`
