# warlock-test-repo

Root of warlock's test repository, holding only the shell test scripts that exercise warlock's pact, scope, check, and ledger (stale/fresh) commands against the sample source tree below it.

## Files

- `check.sh` (4.6 KB) — Bash test script: runs `warlock pact .` then checks each directory's .warlock.md for expected symbols and existence; not application code.
- `incremental.sh` (7.7 KB) — Test script verifying warlock's incremental refresh of engine/core/.warlock.md on file edits, additions, deletions, and .warlockignore handling.
- `scopes.sh` (8.1 KB) — Bash test suite exercising warlock scope add/remove, pact/unpact, check --json, and the gate hook's permissionDecision across nested scopes and sigils.
- `surfaces.sh` (8.3 KB) — Shell test script exercising warlock's `stale`/`fresh` ledger commands and plain/--json output against .warlock/pacts.toml, checking partitioning, unpact, and manifest round-trip.

## Directories

- `data/` — Inventory JSON dataset, its SQL schema, and a binary logo asset; go here for inventory data or schema questions.
- `docs/` — Empty directory with no files or subdirectories.
- `engine/` — Holds core/ with ledger entry, balance-check, and hashing primitives; go here for accounting or hashing logic.
- `infra/` — Terraform config provisioning an artifacts S3 bucket; go here for infrastructure or bucket questions.
- `legacy/` — C frame codec (Frame struct, encode()) plus a stub C++ decoder class; go here for legacy codec questions.
- `monolith/` — Flat Go/Python/TypeScript domain modules with duplicated Apply/Resolve/Compact/etc. worker types and a shared schema.sql; go here for ledger, invoice, tenant, and similar domain logic.
- `pipeline/` — Pipeline.Stage Elixir module summing items, with its test suite; go here for stage/run logic.
- `services/` — Groups api/ (server boot on 0.0.0.0:8080) and billing/ (Invoice, Ledger, Payment, Refund types); go here for service or billing questions.
- `tools/` — Holds scripts/ with build/deploy, inventory (Shelf), and report (Report) utilities and tests; go here for deploy/inventory/report logic.
- `web/` — Holds src/ with fetchCart API client, legacy retry(fn) utility, and Cart component; go here for cart or retry logic.
