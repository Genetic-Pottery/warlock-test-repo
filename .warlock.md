# warlock-test-repo

Root of the warlock-test-repo fixture repository, holding shell test scripts that exercise warlock's pact, scope, check, unpact, and incremental-refresh behavior against the surrounding sample codebase.

## Files

- `check.sh` (6.2 KB) — Test script: re-pacts the fixture repo with warlock, restores infra-ops/warlock-test scopes, then asserts expected symbols and .warlock.md files exist
- `incremental.sh` (7.7 KB) — Shell test script verifying warlock's incremental refresh of engine/core/.warlock.md on file add/change/delete and .warlockignore handling.
- `scopes.sh` (8.1 KB) — Shell test suite exercising `warlock scope`/`check`/`unpact` semantics: scope inheritance, sigil membership, gate hook decisions, and manifest mutation refusals.
- `surfaces.sh` (15.8 KB) — Shell test script exercising warlock stale/fresh/push/unpact against a sandboxed pacts.toml, checking exit codes, JSON output, and manifest idempotence.

## Directories

- `data/` — Inventory data store: a large JSON records file, its SQL schema, and a binary logo asset.
- `docs/` — Documentation directory with no listed files or subdirectories.
- `engine/` — Holds core/, implementing ledger primitives: balance checks, hashing, entry posting/reversal.
- `infra/` — Terraform config provisioning an AWS S3 artifacts bucket, with region variable and bucket_name output.
- `legacy/` — Legacy frame codec: a C struct-and-function encoder with header, plus a separate C++ frame-count-validating decoder.
- `monolith/` — Flat Go/Python/TypeScript modules modeling billing/ops entities via near-duplicated store, repo, projection, and gateway patterns, plus a shared SQL schema.
- `pipeline/` — Provides Pipeline.Stage, an Elixir module summing a list of items, with ExUnit tests.
- `services/` — Holds api/ (entry point, Server struct, boot sequence) and billing/ (invoices, ledger entries, payments, refunds).
- `tools/` — Holds scripts/, covering deploy staging, Ruby inventory modeling, and Python report generation.
- `web/` — Holds src/, root-level source utilities: a cart-fetching API stub and a legacy retry helper.
