# warlock-test-repo

Shell-based test suite and fixture repository for warlock, exercising pact generation, incremental refresh, scope/gate behavior, and stale/fresh surface checks across a sample multi-language codebase.

## Files

- `check.sh` (6.5 KB) — Bash test harness that re-pacts the fixture repo and asserts expected symbols appear in each directory's .warlock.md.
- `incremental.sh` (7.7 KB) — Shell test script exercising warlock's incremental refresh: verifies changed/new/deleted files and .warlockignore updates .warlock.md without disturbing unrelated lines.
- `scopes.sh` (8.1 KB) — Shell test suite exercising warlock scope/pact/check/gate behavior across nested directories, sigils, and manifest mutations against a sandboxed pacts.toml.
- `surfaces.sh` (15.8 KB) — Shell test script exercising warlock stale/fresh/push/unpact against a sandboxed pacts.toml, checking exit codes, JSON output, and manifest idempotence.

## Directories

- `data/` — Inventory data store with JSON records, SQL schema, and a binary logo asset; check there for inventory table or record questions.
- `docs/` — Empty documentation directory with no files or subdirectories listed.
- `engine/` — Container directory wrapping core/, which implements ledger balance, hashing, and entry posting/reversal primitives.
- `infra/` — Terraform config provisioning an S3 artifacts bucket; check there for infrastructure or bucket_name questions.
- `legacy/` — C frame encoder/header paired with a C++ frame-count decoder; check there for Frame, encode(), or decode() questions.
- `monolith/` — Flat Go/Python/TypeScript modules with near-duplicated store, repo, projection, and gateway patterns across many billing/ops entities, plus a shared SQL schema.
- `pipeline/` — Elixir Pipeline.Stage module summing item lists, with accompanying ExUnit tests.
- `services/` — API entry point/boot sequence and billing entities for invoices, ledgers, payments, and refunds.
- `tools/` — Holds a scripts subdirectory of deploy, inventory, and reporting code; no files of its own.
- `web/` — Root-level web source utilities: cart-fetching API stub and legacy retry helper, plus cart component and tests.
