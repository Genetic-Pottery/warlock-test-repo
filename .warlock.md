# warlock-test-repo

Root of the warlock-test-repo test suite, holding shell scripts that exercise warlock's pact, incremental refresh, scope, and CLI surface behaviors against the repo's source tree.

## Files

- `check.sh` (4.6 KB) — Bash test script: runs `warlock pact .` then checks each directory's .warlock.md for expected symbols and existence; not application code.
- `incremental.sh` (7.7 KB) — Test script verifying warlock's incremental refresh of engine/core/.warlock.md on file edits, additions, deletions, and .warlockignore handling.
- `scopes.sh` (8.1 KB) — Bash test suite exercising warlock scope add/remove, pact/unpact, check --json, and the gate hook's permissionDecision across nested scopes and sigils.
- `surfaces.sh` (15.8 KB) — Shell test suite exercising warlock's stale/fresh/push/unpact CLI surfaces against the pacts.toml manifest and briefs, restoring state on exit via trap cleanup.

## Directories

- `data/` — Holds inventory.json, logo.bin, and schema.sql; go there for inventory data shape or the inventory table schema.
- `docs/` — Empty directory with no files or subdirectories.
- `engine/` — Holds the core subdirectory of ledger, balance-check, and hashing primitives; go there for accounting or hashing logic.
- `infra/` — Holds main.tf provisioning the artifacts S3 bucket; go there for infrastructure or bucket questions.
- `legacy/` — Holds codec.c, codec.h, and decoder.cpp implementing a legacy frame codec; go there for encode/decode or Frame struct questions.
- `monolith/` — Flat collection of duplicate-ridden Go/Python/TypeScript domain modules (ledger, invoice, tenant, etc.) plus schema.sql and clock.ts; go there for any domain worker/gateway logic.
- `pipeline/` — Holds stage.ex and stage_test.exs defining and testing Pipeline.Stage.run/1; go there for pipeline stage logic.
- `services/` — Holds api/ and billing/ subdirectories; go there for API server startup or billing domain types.
- `tools/` — Holds scripts/ with build/deploy, inventory, and report utilities and their tests; go there for deploy, inventory, or report questions.
- `web/` — Holds src/ with the cart API client, retry utility, and Cart component; go there for cart or retry logic.
