# services

Groups the service-level subsystems of the application, covering the API entry point and boot sequence alongside billing entities for invoices, ledgers, payments, and refunds.

## Directories

- `api/` — Entry point for the API service with the Server struct and boot sequence; check there for startup or listening-address questions.
- `billing/` — Billing entities for invoices, ledger entries, payments, and refunds; check there for totals, sums, settlement, or refund eligibility questions.
