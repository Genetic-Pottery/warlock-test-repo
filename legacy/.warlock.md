# legacy

Holds legacy frame codec code: a C struct-and-function encoder paired with its header, plus a separate C++ decoder that validates frame counts.

## Files

- `codec.c` (390 B) — Defines Frame struct and encode(), summing a fixed loop plus frame->len; tracks CODEC_VERSION and static frames_seen counter.
- `codec.h` (110 B) — Header declaring CODEC_VERSION constant and encode(struct Frame*) function for frame encoding.
- `decoder.cpp` (263 B) — Defines legacy::Decoder with decode(int id), comparing kMaxFrames-based loop total against id; a simple frame-count check.
