# scripts

Collection of deployment and inventory/reporting scripts along with their tests, covering shell-based deploy staging, Ruby inventory modeling, and Python report generation.

## Files

- `deploy.sh` (99 B) — Shell script setting REGION=eu-west-1 and looping through build, test, ship stages, echoing each stage name.
- `inventory.rb` (256 B) — Defines Inventory module with SHELF_LIMIT constant, Shelf class (count sums items), and self.build to create a Shelf. · declares `Inventory`, `Shelf`, `initialize`, `count`, `self.build`
- `inventory_spec.rb` (252 B) — RSpec spec for Inventory::Shelf, testing item counting behavior
- `report.py` (360 B) — Defines Report class with rows and total(), plus build_report()/build_report_async() factories; REPORT_VERSION=3, DEFAULT_ROWS=100 constants. · declares `build_report_async`, `Report`, `__init__`, `total`, `build_report`
- `test_report.py` (224 B) — Test module with test_report_totals_its_rows, verifying report row totals compute correctly.
